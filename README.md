
# Transcriptomic Data Analysis Pipeline

This repository contains the code for bioinformatics analyses to processes RNA-seq data followed by differential expression analyses and functional analyses.
This repository also contains the code to systematically compare mouse transcriptomes to human disease signatures from the Accelerating Medicines Partnership in Alzheimer’s Disease (AMP-AD) studies (Wan et al., 2020)[https://www.frontiersin.org/journals/aging-neuroscience/articles/10.3389/fnagi.2021.713726/full#B81].


## Installation

Requires:
- R
- SynapseR
- Bioconductor packages

Make sure R and the necessary Bioconductor packages are installed before running the pipeline.


# Transcriptomic Data Analysis Pipeline

This repository contains the code for bioinformatics analyses to processes RNA-seq data to generate normalized expression matrices and perform differential expression analysis.


## Installation

Requires:
- R
- SynapseR
- Bioconductor packages

Make sure R and the necessary Bioconductor packages are installed before running the pipeline.
